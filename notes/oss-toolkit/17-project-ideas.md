# 17 Project Ideas

> Build two of these properly instead of ten half finished ones. Recruiters open the repo, not the resume line.

| Project | Level | What You Build | Stack | Why It Stands Out | Time |
|---|---|---|---|---|---|
| Resume to job matcher agent | Beginner | Parses a resume, extracts skills, searches live job boards and ranks openings with a fit score and gap list | Docling, Qdrant, Pydantic AI, Streamlit | Directly useful to every student around you, so you get real users fast | 1 week |
| College notes RAG bot | Beginner | Ingests semester PDFs and answers questions with page citations and a confidence score | Docling, Chroma, LlamaIndex, Chainlit | Shows you understand chunking and citation, not just a vector database call | 5 days |
| Personal MCP server | Beginner | Exposes your own data, calendar, notes or tracker as tools any MCP client can use | FastMCP, SQLite | MCP is on every 2026 job description and very few candidates have shipped one | 3 days |
| WhatsApp study agent | Intermediate | Answers doubts, sends daily practice problems and tracks streaks over WhatsApp | OpenClaw or n8n, Postgres, Qwen3 | Meets Indian students where they already are instead of on a web app | 1 week |
| Multi agent research analyst | Intermediate | Planner, researcher, critic and writer agents produce a sourced report with fact checking | LangGraph, Firecrawl, Langfuse | Demonstrates orchestration, state and self correction in one build | 2 weeks |
| Voice interview coach | Intermediate | Real time mock interview over voice with barge in, follow up questions and a scored transcript | Pipecat, faster-whisper, Kokoro, Silero VAD | Voice agents are hard and very few portfolios have a working one | 2 weeks |
| Codebase onboarding agent | Intermediate | Indexes a repository and answers architecture questions, then opens a first issue pull request | LlamaIndex, tree-sitter, OpenHands | Solves a problem every engineering team actually has | 2 weeks |
| Invoice and expense agent | Intermediate | Reads scanned bills in Hindi and English, extracts line items and pushes them to a sheet | Surya, Docling, Instructor, Postgres | Document AI on Indian paperwork is a real and paid problem | 2 weeks |
| Self hosted agent platform | Advanced | Multi tenant runtime where users create agents, connect MCP servers and see traces | LangGraph, FastAPI, Postgres, Langfuse, Docker | Platform thinking rather than single script thinking | 4 weeks |
| Browser automation agent | Advanced | Fills government or college portal forms end to end with screenshot verification at each step | browser-use, Playwright, E2B | Handles the ugly real web instead of a clean API | 3 weeks |
| Agent evaluation harness | Advanced | Runs your agent against a task suite, scores it and posts a regression report on every pull request | Inspect AI, DeepEval, GitHub Actions | Evaluation skill is rarer and better paid than building skill | 2 weeks |
| Fine tuned tool calling model | Advanced | Collects traces from your agent, builds a dataset and fine tunes a small model to match a large one | Unsloth, TRL, Qwen3 4B, vLLM | Proves you can cut inference cost by an order of magnitude | 3 weeks |
| GraphRAG over company filings | Advanced | Builds an entity graph across annual reports and answers questions no chunk retrieval can | GraphRAG, Neo4j, Qwen3 | Global questions are where naive RAG visibly breaks | 3 weeks |
| Local first private agent | Advanced | Everything runs on device with no external API call, including speech and retrieval | Ollama, llama.cpp, sqlite-vec, whisper.cpp | Privacy is a real buying criterion, and it proves you understand quantisation | 2 weeks |
