# Exams

One exam per level. Each verifies a claim:

| Exam | Claim | Time | Pass bar |
|---|---|---|---|
| [L1 — The Builder](l1/exam.md) | Can explain the loop and build a working agent. | 2 h | ≥ 70/100 |
| [L2 — The Operator](l2/exam.md) | Can independently build, debug, and eval a production agent. | 3 h | ≥ 70/100 and ≥ 18/30 practical |
| [L3 — The Architect](l3/exam.md) | Can judge: positions, platforms, org-scale design. | 3 h | ≥ 70/100 and ≥ 18/30 memo |

## How an exam works

1. Sit the written sections closed-book, inside the time budget (honor system).
2. Do the practical in `l*/practical/` — a pytest-scored project that runs offline, no API keys.
3. Score yourself against `l*/key.md`. Every key entry is point-anchored ("award 3 pts if …"),
   so two graders land on the same score.

The written parts of each exam also render into the book PDF as the final Assessment part.
The keys never do.
